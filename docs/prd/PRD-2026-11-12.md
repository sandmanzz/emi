## 1. Event Status flag "Allow Add Item"

> Owner: "tambahkan opsi juga untuk allow add item, jadi kalau allow maka user masih bisa add dan kalau no maka user sudah
> tidak bisa add item lagi. tujuannya untuk menjaga agar tidak ada penambahan di akhir."

- Field `allowAddItem: boolean` on each Event Status. **Missing = true** (status lists saved before this keep working).
- Event Settings (Event Status page): column **Allow Add Item** (between Check Ownership and Allow Delete), KPI card,
  form field True/False with the hint "When False, nothing can be added to an event at this status…".
- Event Detail, while the event is at a stage with `allowAddItem = false`:
  - **Add Item** button disabled (tooltip: `Adding items is off at "<stage>" (Event Settings → Allow Add Item)`);
  - **Rent Item, Outsource Item, Request Production** hidden; "Create Production" on a broken item disabled;
  - lock note: `Adding items is off at "<stage>" (Event Settings → Allow Add Item = False). Rent, Outsource and Production
    requests are off too.`
- It is **per current stage**: going back to a stage with True allows adding again (unlike Stock Return, which locks for
  good once reached). Both rules combine: `addLocked = stockReturnReached || !allowAddItem(current stage)`.
- **[ASSUMPTION]** "add item" covers Rent / Outsource / Production, since those also add lines to the event.
- Seed (`src/data/eventStatuses.js`): False for Waiting scan in, Event running, Waiting scan out, Finished; True elsewhere.
- Code: `isAddAllowedStage()` in `src/lib/eventStatuses.js`; `stockReturnLocked`, `addNotAllowedHere`, `addLocked` in
  `src/pages/EventDetailPage.jsx`; `src/pages/EventStatusPage.jsx`.
- Backend: `POST /events/{id}/items`, `/rentals`, `/outsource-orders`, `/productions` → `409 ADD_NOT_ALLOWED_AT_STAGE`
  when the event's current stage has `allowAddItem = false`.
- Mobile: hide/disable every "add" entry point with the same rule.

Verified: lint 11, build OK; Chromium — Product Photoshoot Kilau (Waiting scan in) Add Item disabled with the lock note;
Intimate Dinner Ubud (On preparing items) Add Item enabled; Event Status table shows the new column.
